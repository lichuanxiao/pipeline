# 用户页面与操作交互

覆盖 WEB-01 至 WEB-05，并将 CMDB、市场、编辑和执行连接为完整用户路径。本方案采用操作型控制台：优先呈现当前任务、目标、状态与下一步动作。此阶段确定功能结构与交互，不交付视觉稿、可运行页面或已确认配色。

## WEB-01 导航、空间与应用上下文

登录后进入上次有权访问的空间；原空间不可访问时进入空间选择，不把用户送到403死路。无空间时显示“尚未分配空间”，平台管理员有创建入口，普通成员看到联系管理员说明。顶部固定空间切换、面包屑、待我操作与个人菜单。

空间侧栏：概览、应用（按子系统筛选）、流水线、运行历史、Job市场、发布计划、待我操作、空间设置。系统管理员另有系统设置，普通用户不显示无权入口。应用详情使用概览、交付配置、流水线、执行历史、镜像与部署、变更记录页签；不要求用户先理解所有技术模块。

URL包含spaceId与稳定资源ID，面包屑提供空间→应用→流水线→Run，运行详情可直接分享。切换空间前处理未保存编辑，清理旧空间数据缓存，再加载新权限。跨空间深链接无权显示统一不可访问页和返回空间选择，不泄露对象名称。

空间概览先展示等待人工、失败、排队过久、状态不明等当前异常。待我操作按当前权限查询当前Stage的WAITING_MANUAL Job，提供应用、环境、等待时长、目标摘要和进入详情；不在列表直接批量部署。已放行或失去权限的项自动移除。

**验收：** 深链接刷新保持对象与筛选；空间切换不闪现旧数据；不同角色入口准确；原空间被移除后能回到可用空间。

|---|---|---|

| 空间概览 | /s/{spaceId} | 待处理、异常、最近交付，进入Run |
| 应用列表与子系统分类 | /s/{spaceId}/applications | 搜索筛选、缺配置提示、新建应用 |
| 应用详情 | /s/{spaceId}/apps/{appId} | 身份、负责人、交付就绪、流水线入口 |
| 交付配置 | /s/{spaceId}/apps/{appId}/delivery | 代码、镜像、环境目标，保存/验证 |
| 流水线列表/详情 | /s/{spaceId}/pipelines、/pipelines/{id} | 修订、草稿、环境、最近Run，编辑/运行 |
| 流水线编辑 | /s/{spaceId}/pipelines/{id}/edit | Stage/Job与配置面板，保存/校验发布 |

| 市场/能力详情 | /s/{spaceId}/catalog、/catalog/{id} | 分类、版本、契约、示例，编辑器内选择 |
| 发布计划 | /s/{spaceId}/releases、/releases/{id} | 应用commit、交付汇总，逐应用运行 |
| 待我操作 | /s/{spaceId}/pending | 有权手动Job、等待时长，查看后触发 |
| 空间设置 | /s/{spaceId}/settings | 成员、角色、环境、引用与配额查看 |
| 系统设置 | /admin | 账号、空间、Controller、节点池、模板发布 |

表内简写/pipelines/{id}、/runs/{id}等都继承同一/s/{spaceId}前缀，不是跨空间全局入口。

## WEB-02 表单、列表与 Job 市场

新建应用先最少身份字段，再提示交付配置；不要求一次填写所有基础设施参数。配置按代码、镜像、环境分组；目标展示集群+Namespace+Deployment+容器，不能只写“生产”。保存与连接验证独立，验证显示时间和配置版本。

必填字段就地标记，帮助文案说明格式与用途，错误就地显示并聚焦首项；后端冲突保留输入。成员/集群/凭据选择器异步加载，加载失败保留已选值和重试入口。密钥引用只显示别名、用途、验证状态，不提供取回原密码功能。

列表共享搜索、筛选、分页和空状态，但字段按业务组织；删除、归档、停用使用明确动作名称，确认框展示对象与影响，普通保存不重复确认。写请求防重复点击，响应不明时先查询幂等结果，不换键盲目创建。

市场卡片展示用途和效果，详情展示输入输出、版本和示例；“添加到当前Stage”仅在编辑器上下文出现。空市场解释由谁发布，不提供不可执行占位卡片。模板管理和浏览分开，业务用户不进入脚本编辑页。

**验收：** 从空空间能按引导建好第一个应用；错误字段可定位且输入不丢；权限不足有说明；市场选完返回原Stage。

## WEB-03 编辑器布局与操作

桌面分为顶部流水线身份/保存状态/发布，中部纵向Stage和组内并行Job，右侧选中任务配置。配置面板展示名称、模板固定版本、自动/手动、超时和输入绑定。窄屏改为配置抽屉，保持单一主滚动方向。

```text
应用 / 流水线       草稿：已保存           [查看修订] [校验并发布]
运行参数：release_note …

Stage 1 质量检查       [上移][下移][添加任务][更多]
  [单元测试 自动]  [静态检查 自动]      ← 同组并行
           ↓ 全部成功后继续
Stage 2 镜像构建
  [构建并推送 自动]
           ↓
Stage 3 应用部署
  [Kubernetes部署 手动]

选中任务：名称 / 版本 / 自动或手动 / 参数来源 / 超时
校验问题：点击定位到 Stage、Job 和具体字段
```

选中节点不弹确认，删除有引用时先展示影响。改名、移动、复制可撤销；引用非法时节点与字段都有错误标记，连线不是唯一表达。输入来源显示“构建镜像 → image_ref”，可展开技术key。

发布前先确保草稿保存成功，再展示结构化差异、人工点和变更说明。发布成功显示新修订编号，并给“运行此修订”入口，不自动运行。无编辑权限显示只读状态，历史修订查看不能伪装可编辑。

**验收：** 键盘可新增、重排、配置、定位错误并发布；保存状态准确；发布与Run独立；长名称和20Stage不产生无限横向页面。

## WEB-04 运行、日志和历史

运行面板显示修订、环境、代码、参数、可选计划和目标摘要。protected环境突出保护标签并要求原因；创建成功进入详情。预检失败保留面板输入和可修复项，不跳到空Run详情。

详情头部固定应用、环境、Run编号、主状态、syncState、最后更新、代码SHA和首要动作。次级区显示排队/人工等待/执行时长、修订、创建者与Release；图中展示Stage顺序和并行Job。点Job查看摘要、日志、输入输出、执行环境、时间线。

| 状态 | 用户反馈与动作 |
|---|---|
| 应用互斥/容量排队 | 原因、前置Run链接、等待时长，可取消 |
| 准备中 | 源码解析和最终commit，业务Stage尚未开始 |
| 自动运行且有手动等待 | 主状态运行中，显示待人工计数，手动按钮可用 |
| 只剩人工等待 | 截止时间、可操作角色、镜像目标与“执行此任务” |
| 失败收敛中 | 已停止新任务，兄弟任务继续显示真实执行和日志 |
| 取消中 | 区分已停止和待核对，不提供再次开始 |
| 状态不明 | 最后已知状态/时间、自动核对与管理员入口 |
| 已结束 | 结果、原因、产物与部署、重新运行 |
| 日志过期/缺失/同步中 | 各自明确说明，仍保留结构化结果 |

手动确认只针对当前Job，展示快照目标和digest，不能在此改参数。409/403后刷新状态并解释，不维持过期按钮。取消说明“已发生的外部变更不会自动回滚”。

日志默认跟随，用户上滚暂停并可“回到最新”；搜索说明仅已加载内容，全量归档下载需鉴权。新事件只更新相关区域，不重置焦点、滚动、选中Job。SSE断线显示恢复中并退避重连，可降级5秒轮询同一当前API，这是故障处理，不是旧协议兼容。

历史展示快照和真实部署，重新运行创建新ID并展示当前上下文差异。计划页分别展示运行与部署，不把一条绿色测试Run当作整个计划已交付。

**验收：** 自动/手动混合清楚；断线不停止执行；已部署但Run失败可解释；大日志、过期与权限撤销均有明确状态。

## WEB-05 可访问性、响应式与异常状态

以[WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/)作为实施目标：键盘可达、焦点可见、标签与错误关联，状态同时用文字/图标。拖拽有按钮替代；抽屉/对话框管理焦点并在关闭后回到触发点；执行图有可读列表等价表达。

桌面1440/1280宽高密度操作；768宽使用配置抽屉；375宽保留查看、运行、手动、取消和基础编辑，Stage纵向、Job折叠，表格转关键字段列表。复杂JSON可文件导入导出，不要求移动端使用横向画布。触控目标至少24 CSS px且有间隔，常用动作推荐44px，依据[W3C目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)。

各页面覆盖首次/局部加载、空、无权、404、503、数据陈旧、保存冲突、会话过期。登录失效保留内存中非敏感编辑，引导登录后核对ETag；不在URL/localStorage保存凭据。系统错误给requestId与重试，结果不明先对账。

时间按用户时区并显示绝对时间；aria-live温和播报状态，不逐行播日志。长文本折行/展开，危险动作与原因不只靠悬浮说明。具体视觉稿在实施时细化，不改变已写明的业务规则。

组件库推荐Ant Design，与工程章节一致；本章尚未设计具体视觉稿，实施时以中等信息密度、可读表格、清晰状态文字和稳定布局落地，不增加与操作无关的装饰。

**验收：** 375/768/1440宽与键盘关键流程可用；慢网/断网无假成功；退出/切空间后旧数据不可见；100Job和大日志下可操作。
